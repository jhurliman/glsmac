# Base inspector production information

The canonical inspector reads the current production name and all saved queue
entries from a native, read-only projection. Names come from frozen source
catalogs or the owned custom-design presentation. Name resolution does not make
an item eligible or complete it. Unconfigured and empty queues remain distinct;
the state setter/serialization format has not gained presentation fields.

The queue displays its complete ordered contents with vertical scrolling.
Change opens the existing authenticated production picker; its choices also
scroll within the popup. Selection, loss confirmation, Cancel and stale-state
rejection continue through the existing native command. The queue is explicitly
read-only and Hurry explicitly unavailable. Mineral stores are real; production
forecasts and item artwork remain unfinished.

Focused validation covers a native Base's nine-entry mixed queue and current
item without snapshot or RNG mutation; the actual GSE stored-panel methods for
nine entries, empty and unconfigured queues; and all existing production-picker
groups, including real events, retool loss/cancel, stale clicks, ownership,
facility completion and saved turns. Targeted clang-tidy15 covers Base.cpp.
These checks do not establish rendered layout or the installed Planet launch
route. Those require the separate map admission and rendered milestone work.
