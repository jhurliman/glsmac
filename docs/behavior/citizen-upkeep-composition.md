# Citizens and status within ordinary Base upkeep

RE-SMAC-CITIZEN-UPKEEP-COMPOSITION-001, 2026-10-18. Pinned stock SMAC.
[Literal caller cases](citizen-upkeep-composition-cases.json).

**Production and food/population processing precede the Golden Age/riot status
check. Newly admitted Golden Age does not retroactively affect that pass's
growth. Incoming saved riots gate mineral posting before their later recovery.**
These conclusions extend the frozen citizen arithmetic; they do not replace it.

## Actual order and input authority

For the admitted unmanaged local human, surviving Base, turn counter greater
than1, the original caller executes:

1. Support, intake, nutrients, minerals, energy and complete citizen calculation.
2. Production, including mineral posting, completion, local grant or Unit
   creation/Colony population debit; secondary production; outer baseline commit.
3. Food/population processing. A surviving population change can itself run a
   complete resource/citizen calculation. The caller then checks mineral deficit.
4. A second **unconditional** support/intake/nutrient/mineral/energy/citizen pass.
5. Golden Age/riot admission using current population and the final talents and
   drones stored by that preceding calculation.
6. Post-status specialist policy, then later research, cache validation, ecology,
   income and the remaining Base tail.

The status routine does not calculate citizens or allocate Psych. It reads
current population, retained final talents/drones, incoming status and protection
authorities. It does not directly read Psych points, worker masks, specialist
count or extra drone burden. Those values matter through the preceding real
citizen pipeline. The initial saved talents/drones/burden are poisoned77/66/55 in
these controls and are replaced before production. Neither those entry canaries
nor a frozen pre-completion citizen snapshot supplies status admission.

The second pass includes completed local facilities, the current population
after Colony debit and any subsequent growth, current worker allocation,
specialists and resolved energy/Psych. The checked citizen predicate remains
the existing [Golden Age/riot contract](golden-age-and-riot-admission.md): minimum
population3, zero drones and talents at least the rounded-up half for Golden Age;
strict drones greater than talents for unprotected riot admission. Turn0/1 skips
this status stage in the caller; existing boundary controls remain authoritative.

## Colony debit and later population

At store29 with actual Pod cost30 and surplus1, production creates the Pod and
debits population3 to2 **before** food processing. At store28 the Pod does not
complete and population stays3.

- With food0, the debit case reaches status at population2, food2, talents2 and
  drones0, so it cannot begin Golden Age. The no-debit control reaches status
  at population3 and begins Golden Age. If the debit case enters already in
  Golden Age, status ends it at population2.
- With food33, the debit case reaches food processing at population2, then
  immediately grows back to3 because its reduced box capacity is30. Status
  sees the resulting population3 and begins Golden Age. Checking immediately
  after the Colony debit would give the wrong answer for this pass.

These ordinary size3 controls do not enter the separate size-one abandonment
question or establish its notification/continuation behavior.

## Publication and limits

For an atomic port transaction, retain incoming status for the stages that
consume it, apply production/grants/debits, process food/population, recalculate
the final candidate resource/citizen state, then derive candidate status.
Publish the resulting coherent state once. Later legitimate queries can use
new Golden Age, but this is not permission to recompute earlier food/mineral
posting under that new status. Existing later cache/continuation rules still
apply; this receipt does not add an unconditional post-status resource pass.

Ten ordinary Unit/Colony controls execute through complete Base caller returns
without production cleanup jumps. Two additional facility controls return through
the same caller after omitting reached production cleanup tails by continuing at
the original production epilogue. All twelve run population, second resources
and status, and receive a post-return nutrient-cost query. No faction caller,
map/graphics/UI observation or new riot
consequence branch is claimed. Notifications, completion history, UI object
destructors and deallocation services are supplied; the fixture names reached
notifications, including PRODUCE, GOLDENAGE and GOLDENAGEOVER. Notification-driven
interventions are omitted. The facility cleanup omission is the same declared
boundary used by the earlier upkeep-production harness; it supplies no grant,
citizen or status result. Existing headless
first-world TLS/interface services remain supplied. Full Base return does not
mean an unsubstituted desktop game run.

The complete caller can also consume a later ecology event-roll draw; that is
separate from citizen/status arithmetic and is not presented as a zero-RNG turn.
Frozen earlier arithmetic, status, growth, production and Colony receipts are
unchanged. No production or installed asset changes; the broad goal stays paused.
