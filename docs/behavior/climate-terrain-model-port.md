# Climate terrain model integration checkpoint

This model closes the detached scalar passes, not the complete
live climate transaction or a rendered acceptance gate.

`map/SmacClimate` implements ordered altitude reconstruction/height shaping,
admitted ecology volcanic geometry, temperature, rivers and rainfall against one
evolving owned plane. It retains the seven remembered item words, cached occupant,
rockiness, contours, climate auxiliary byte, landmark detail/dirty bits, per-call
flood scratch and Mount Planet center. Shared/CRT requests use the existing two
independent gameplay streams. Optional traces do not choose or replace draws.

All34 original controls pass complete 3,200-tile byte reconstruction hashes,
shared/CRT final states and draw counts, seed requests and literal CRT outputs.
The composed rising/falling/after-volcano cases compare the first four passes
before region rebuilding. The probe preserves opaque input bytes when encoding
its semantic outputs. A hash-verified prepared Planet input was reconstructed
locally from the purchased installed asset plus the existing private native
admission receipt. That original map is not distributed with the port.

Reproduce twelve asset-free controls: the seven original synthetic river worlds
and five retained-altitude-band7 controls:

```sh
g++ -std=c++17 -O1 -g -Isrc tools/tests/smac_climate_probe.cpp \
  src/game/backend/map/SmacClimate.cpp \
  src/game/backend/map/SmacPlanetMap.cpp \
  src/game/backend/SmacGameplayRandomState.cpp -o /tmp/smac-climate-probe
python3 tools/verify_smac_climate.py --probe /tmp/smac-climate-probe
```

The optional `--prepared-planet PATH` accepts the local140,800-byte prepared plane
with the exact frozen hash and enables all43 controls, including nine
[retained-band7 comparisons](climate-retained-class7.md). It validates every test
input hash before evaluating any expected output. Recipe edits for synthetic
worlds and feature discriminators are explicit; no output is used to manufacture
its own expected result. The after-volcano input is separately pinned by the
original volcanic geometry output hash.

The normal native suite also compares every semantic field of all3,200 tiles for
each of the seven original synthetic worlds. A separate callback-boundary test
checks landmark invalidation, masking all positive remembered item snapshots,
entity cleanup admission and final class storage in source order, plus per-call
flood scratch reset. Eight selected native groups pass. Targeted C++ correctness
analysis passes SmacClimate.cpp. Fresh ASan/UBSan instrumentation of the standalone
production model/probe passes all34 complete-plane controls (leaks disabled).
