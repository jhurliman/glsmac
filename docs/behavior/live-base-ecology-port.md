# Live Base ecology calculation

The ordinary and upkeep resource passes now calculate eco-damage using the
measured rules in `SmacEcology.cpp`. The fresh GSE resource result exposes
`eco_damage`; an unavailable authority produces `null`, never an invented zero.

The consumer reads every valid square of the 21-square radius, including
unworked and unowned improvements. Worked status comes from the explicit
allocation bits, including the independently retained center bit. It uses the
actual gross processed minerals before support, candidate population, mining
satellites, authenticated installed/staged local facility roles, current PLANET,
retained technology score and Future Tech counter, owner/global difficulty,
saved clean-mineral/atrocity history, frozen Sea Level Rises rule, mutable world
native life/sea offset and retained perihelion phase. The admitted no-project
campaign establishes absence of Singularity Inductor, Pholus Mutagen and Voice
of Planet; this is not inferred from missing project fields.

No query changes history, posts an aggregate, consumes a CRT/gameplay random
draw or triggers an ecology event. Those owner-tail/event consumers remain to
be integrated in their measured sequence. Opening production for ecological
facilities also requires their event-driven clean-mineral history writer;
this change does not admit those completion targets.

The last committed upkeep pass preserves its damage in inner cache V2. V1
migrates with unavailable damage. Colony continuation V3 carries the same
field; V1/V2 retain absence. Resuming a new known-damage question checks that
the live damage still agrees. A legacy unknown value is not reconstructed
and substituted into its historical first pass. Founding's separately retained
allocator pass remains unavailable until it has an actual ecology calculation.

Focused validation uses the cached native build. The live fixture checks:

- 21 Boreholes, two selected bits: raw terrain points191, scaled23;
  center mineral1 plus capped worker2, clean allowance16, burden10;
  technology100, PLANET0, native life1 and Citizen factor2 give damage20.
- A road on an unworked radius square raises damage to22. Clearing the center
  selection bit reduces it to20 without changing automatic center intake.
- Active perihelion doubles damage to40; retained clean history20 reduces it
  to0 without installing facilities.
- Repeated native/GSE queries preserve the snapshot and both RNG states.
- Actual upkeep retains damage20 and world restore preserves it; removing
  current world authority makes a fresh query unavailable while preserving
  the historical cache.
- Independent typed V1/V2 cache fixtures preserve absence and signed32 damage,
  including137 and both signed boundaries, and reject narrowing/truncation.

The selected native run passes12 groups, including actual Colony saved
questions, deferred Screen/research/Start, campaign restore and perihelion
boundaries. Correctness analysis passes the six changed production translation
units. Seven focused groups also pass with ASan/UBSan instrumentation on the
live calculation, resource processing, cache, production and canonical snapshot
translation units; other objects reuse the current normal build and leak
detection is disabled. This is calculation/cache integration, not a claim that blooms, aggregate
posting, ecological facility completion or every ecological event is playable.
