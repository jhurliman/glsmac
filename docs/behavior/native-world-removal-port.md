using the existing registry, occupancy, knowledge, wrapper and publication plan.

before surface-class storage; this helper does not invent those predicates.

unlinked using its current staged links, then surviving dense identities,
links and order-1 payloads are repaired through the existing record helper.

hook path. Known occupancy clears its Unit-presence bit only for the last member
and retains cached affiliation on the now-empty tile.

accounting independently of live roster counts: qualifying active-plan word
first, then design byte, both with wrapping subtraction. The prepared transaction
owns those writes and exposes them in its private query view. The legacy direct
native path also debits retained factory authority when present. Missing legacy
authority remains absent; canonical world removal requires it. Climate cleanup
must not perform a second debit outside this transaction.
