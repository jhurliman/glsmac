# Live Workshop preset command

`preset_smac_workshop` connects the retained human recommendation controller to
an authenticated, queued Base command. Actions9..22 use original filters
2,3,1,4,10,6,7,8,9,17,13,14,11,12. The request carries the current full draft;
it does not commit it or run the ordinary New/open controller first.

Each admitted request refreshes capabilities once, including an unmatched role.
It uses retained rank, current Fight and four priorities, current Industry,
Base totals, allocation counts and the last owner air summary. It never recounts
air history. Missing authority fails without publishing a partial refresh.
The current admitted faction constructor has innate morale0; social MORALE is
not substituted for that separate input.

The opaque `preset_state` SHA256 covers the existing design/technology/count
fence plus the relevant simulation inputs and combat/campaign rules. It exposes
no opponent cache values. A changed fence returns stale with no mutation.
Foreign banks and malformed requests are rejected before queueing. The command
also uses the existing deferred Colony Screen envelope and ownership checks.

Successful preparation atomically publishes only the resulting design registry
and refreshed capability state. The response contains the new selection,
matched/no-result status and original feedback43/39. An unavailable category
preserves the inherited draft, including reactor, name and full ability mask.
Normal response painting retains its separate selected-design resolution.
