# Global wildlife policy integration

`map/SmacGlobalWildlife` implements the reachable fauna decisions after the
forest/kelp pass in stock `537790`. It owns the incoming RNG copy and preserves
constructor-owned draws before subsequent samples. Sea search consumes its
1000th coordinate pair without testing it. The fungal shortcut deliberately
bypasses the fallback occupancy, region-area and water checks. Broods use the
actual newborn carrier's capacity, passenger sentry operations and stack
promotion; land births and unseen ambushes retain the native ordered search.

Every helper must operate on one detached transaction. Earlier constructor
occupancy and sight effects must be visible to subsequent queries. A failure
requires discarding the whole transaction; this policy does not provide rollback
for an arbitrary hook. Publication and script notifications belong after commit.

This is not activated in the live round controller. The shared birth publisher
now stages mixed Scout/Isle stacks with complete retained links, or binds an
unambiguous legacy singleton. Ambiguous legacy stack order and occupied Base
placement remain guarded. Global maintenance and wildlife upkeep/command phases
also remain separate integration work.

Validation currently covers four asset-free native test groups: no-effect gates,
capacity/order/Locust sequence and entry-only count gating, exact exhausted search
query budget and factory RNG, and no-Base ambush/empty-land/omniscience guards.
The test factory models only the state needed by these structural controls; it
is not proof of original constructor effects or live gameplay. Production-file
analysis and focused two-file ASan/UBSan pass (other linked objects normal,
leak detection disabled). The opt-in `GLSMAC_GLOBAL_WILDLIFE_REFERENCE` test compares all 30 frozen
original policy returns: exact ordered constructor/sentry/head requests, sea/land
coordinate streams, final count and RNG after flora. Point this variable to the
frozen bundle's `tmp/reference` directory. The independent native checker also
passes all 30 returns and reconstructs complete captured write journals. That
constructor evidence does not make the structural C++ test factory a complete
live publisher. Frozen 29-file manifest SHA256:
`47a8927904222c3d49e2ae6790b3b5228b30b4068f91b9ea487950148feec9cd`.

## Shared staged factory

`UnitManager::PrepareNativeBirths` now accepts a synchronous C++ producer. Its
operations create actual staged Units, query the admitted native capacity, set
sentry fields, promote a stack head, and read the resulting staged record.
The ecology-plan entry point uses this same factory. Publication and spawn hooks
remain separate Commit/Notify steps. The operations must not escape the producer,
yield, invoke scripts, or suppress an operation failure and publish partial work.

The brood integration test creates an Isle and two sentry passengers, promotes
the Isle, then creates a Locust. It checks intermediate and final links, unchanged
live state on discard/failure, atomic publication and full world save/reload.
Existing birth and sight fixtures continue to run through the shared factory.
Mixed-owner co-location and the broader native assignment/RNG tail still require
their missing authorities; this API does not silently bypass those guards.

## Conventional stack authority (integration in progress)

Conventional Unit8 optionally retains source-pool ID and next/previous links.
Unit4/6/7 remain readable and leave this authority unknown. The ordinary codec
refuses to omit a supplied binding; field and manager graph validation reject
self-links, out-of-range indices, nonreciprocal links, cycles and missing physical
members. Native and conventional bindings use the same dense registry order.

Direct and prepared casualties unlink either kind before source-pool compaction.
Prepared queries/commit include conventional links separately from home changes,
and copied faction-removal plans preserve that state. Six lifecycle controls
remove each member of a retained Isle -> Worm -> Scout stack through direct and
prepared paths, check discard isolation, then roundtrip all surviving Unit bytes
through the manager codec. These are explicit retained-state fixtures, not a
claim that the original constructor has already produced that stack in GLSMAC.

The factory now inserts/promotes across both kinds and exposes staged knowledge
to subsequent producer decisions. A controlled integration test reproduces the
captured Isle -> Worm -> Scout ordering, co-located observation and exploration
writes, and retained positive affiliation, translated from owner2/source indices
13/14/15 to fixture owner1/indices0/1/2. Conventional body fields remain unchanged
apart from their new binding. Discard/producer failure publishes nothing; full
world restore retains the complete resulting stack and sight authorities. This
is a component comparison, not byte-exact original conventional Unit equivalence.

Ordinary movement maintains retained links. After separately supplying ordinary
nonfungus geometry, the integration test removes native members, moves the Scout,
joins a friendly legacy singleton, prepares/discards another conventional birth,
then commits that birth with a simultaneous casualty and checks reindexing.
Stat/owner/home updates cannot overwrite a separately published stack binding.
Conventional births on a known stack share the same insertion preparation;
unpublished insertion changes are projected into combined removal transactions.

Still required before global activation: authenticated initial/restart stack
bindings for new worlds; an explicit policy for ambiguous legacy stacks; mixed
Base-center cleanup; occupied Base factory admission; same-tile enemy departure
and remote fungus-with-Bases continuations; and the actual wildlife upkeep/AI
phases. Those existing admission guards remain. Global policy never adds a
filter to conceal a reachable original result.

Validation for the mixed-stack change: 106 affected conventional/native/movement
groups pass normally and with eight changed/affected translation units under
ASan/UBSan (other objects normal, leak detection disabled, UBSan halts on error).
Five production files pass targeted analysis; the two insertion consumers were
reanalyzed after their final edits. The final whole-knowledge restore assertion
also passes normally and under the focused sanitizer binary.

## Connected controller reference

and its [four boundary controls](behavior/global-wildlife-owner-transition-cases.json)
now cover global generation through the first positive-owner upkeep entry. The

`003ba9d7c15b7861a0c8018691a7daeadf5ad561342ca67001e87e896c1ba437`.
All manifest hashes and the independent non-stack-write/boundary checker pass.
This is source evidence, not an activated GLSMAC controller or a played AI match.

The implementation order is global flora/fauna, resource-event maintenance,
conditional territory/region/goal refill, native owner upkeep/planning, native
commands, then positive-owner upkeep. Even an empty wildlife roster performs
retained planning work. A landlocked newborn Isle is deleted during planning;
the last Worm is compacted into its source index before command dispatch. Never
reuse a pre-upkeep roster or advance the cursor by treating these phases as empty.
Native command scoring uses CRT draws; movement has separately observed shared
RNG calls. Keep those streams and constructor effects in execution order.

Before calling the existing global kernels, compose a detached current native
map plane. The immutable imported Planet container is not the live plane:
terraforming, fungus, exploration, remembered improvements, occupancy, regions
and claims have independent current owners. `Map::CopyNativeTerrain` is a render
snapshot, not a complete packed gameplay record. Preserve opaque retained bytes;
replace only fields with authenticated live authority. Unknown observer memory
must not become current improvements, and cached affiliation must not be rebuilt
by recounting current occupants. Publish flora changes to both physical terrain
and remembered knowledge in the same transaction before fauna queries. Factory
sight and occupancy writes must feed subsequent samples. Keep failure/discard
isolation through the final publication and defer script notifications.

The four command outcomes are integration controls, not a native AI algorithm.
General candidate scoring, traversal, transport handling and movement continuation
still require the original policy. The first-round baseline alone cannot admit
arbitrary spawned-wildlife campaigns. The connected reference also executes no
positive-owner upkeep body; that remains covered by the separate owner contracts.

## Live flora input adapter

`Map::CopyGlobalSpreadInput` now supplies the forest/kelp kernel from current
physical improvements, moisture and rockiness plus actual exploration and
observer memory. It retains unrelated source bytes. Missing memory is rejected
when the observer is explored or omniscient; unobserved unavailable memory is
never replaced with the current improvements. Preparation consumes no RNG and
publishes no map, policy, knowledge, or presentation changes.

This input is scoped to the flora kernel's consumed fields. Unrelated retained
occupancy/site/region words are not current wildlife authority. It cannot be
published through the immutable imported-policy journal as though that source
were the live map. Atomic physical/remembered flora publication and the broader
fauna input plane remain owning-transaction work before controller activation.

A focused integration control changes the actual map after its retained source,
executes the real forest-spread kernel, checks remembered propagation, and checks
that preparation leaves all live authorities unchanged. It also exercises
missing explored/omniscient memory and pending-restore rejection. Six affected
groups pass normally; the same groups pass with the new adapter, spread kernel
and fixture translation units instrumented with ASan/UBSan (other objects normal,
leak detection disabled). Targeted production analysis reports zero diagnostics.
The optional original nine-checkpoint group executes its native evidence in the
sanitizer run; the initial normal run has no private receipt environment.
