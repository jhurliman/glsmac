# Local Governor settings and remembered templates

This inspector slice provides the nineteen measured advanced controls and the actual local Apply branch when no active management callback is needed. It does not implement general Governor AI, production priorities, complete citizen/Psych management or the original dialog artwork.

The native command authenticates the local owned Base, current turn/Base state and owner remembered-template state. It reconstructs the nineteen independent masks, preserves Explore/Discover/Build/Conquer directives, clears unrepresented configuration bits, and atomically publishes both the Base options and the owner's remembered template. The supported local branch requests the measured outer map refresh, even for unchanged options; it is not the configuration-only or bulk command. Inactive options and an active Governor with production, citizen and new-unit automation disabled can Apply. Unsupported active branches are clearly unavailable in the view and rejected before mutation by the native command.

## Saved authority and founding

Simulation V27 appends eight independently optional unsigned32 remembered words. V11–V26 saves retain absence per slot; loading does not infer a template from arbitrary existing Bases or today's difficulty. Fresh admitted owners get the measured difficulty-produced word, including raw startup bits. Actual world retirement/preparation preserves peer/slot0 words and replaces only freshly admitted owners. Nonzero restart retains remembered state.

Starting and later founded Bases copy their actual owner's remembered word. Each existing Base keeps its separate saved options. A development save missing the owner's template can still inspect and manage existing Bases; accepted Governor Apply establishes the template. Founding then proceeds. Before that, founding reports: “Apply Governor settings in an owned Base before founding a new Base.” No guessed legacy default is installed.

Advanced Apply deliberately clears the startup marker when it reconstructs the submitted controls, as the original conversion does. Capture continues copying the measured donor Base configuration independently; it does not overwrite the faction template.

## Transactions and interface

`apply_smac_governor` is a native validated queued command, also admitted through the stamped Colony Screen route. The expected token contains Base/turn state and the owner's optional remembered word, so a change from another Base invalidates stale submissions. Publication reserves frontend updates before any mutation. Retired targets are resolved by cached scalar identity and live registry/wrapper identity before dereferencing a C++ Base.

The existing Base header opens a provisional two-column advanced window. Cancel/Escape discard draft controls. Base refresh/navigation, required questions and turn transitions close the window. The four production directives remain preserved rather than inventing unmeasured priority-button transitions. The port's read-only opening/Cancel behavior is not a claim that the original wrapper has no preliminary cached recalculation.
