# Terrain-aware native Base-name anchors

The original [ordinary geometry](behavior/ordinary-terrain-projection.md) coordinate helper returns a tile box displaced by the floored mean of its four outer heights. The [name caller](behavior/base-map-name-font.md) uses that projector anchor, not the terrain fan center. A coastal band4 tile with outer heights0/25/25/25 therefore uses height18 for the name, while its mesh center remains25.

Finalize now retains that original integer projector displacement independently of the mesh. TileState transports it in a bounded optional tagged extension; old transport without it keeps legacy absence. The frontend Tile forwards it to native Base-name rendering, which keeps the original baseline/bitmap behavior from #318. The name anchor is converted from the original tile-box origin to the port's center representation before projection. Legacy and water names retain the existing fallback. The frontend coastal selection outline now follows the same native fan as the display and click meshes, rather than applying the old coastal corner replacement.

This closes ordinary terrain-aware name placement relative to the current camera. The follow-up [map object anchors](native-map-object-anchors.md) connects Base/Unit/badge and improvement callers to their separately measured original height term; exact local artwork rectangles remain open. Landmark deformation and exact camera/zoom/raster behavior remain open. This is not whole-scene pixel parity, and the original geometry triangles are unchanged.
