prepared newborn loses only its own home; older same-owner homed units move to

record order and joined sight/territory are staged before one callback-free

The compacted successor is the next actual Base record, not the nearest home.

with that retained value and skip a later full production entry. Deleting the
last record returns no successor. Missing cached history, a foreign immediate
successor, and last-owned-Base disposition reject before publication. The latter
needs the separate real restart/disposition integration; this transaction does
not invent a replacement package or placement policy.
