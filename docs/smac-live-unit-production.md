# Live ordinary unit production stage

`Base::ProcessSmacProduction` consumes the actual Upkeep worker calculation and
fresh N/M processing. Nutrient normalization stays private until publication.
The stored-food gate, nonnegative mineral posting, riots suppression, actual
cached target cost, human carry cap and switching baselines use owned inputs.
The pending human unit queue advances in order; an empty queue repeats the
current target. Unit candidates use actual active/exclusion/prerequisite/owner
and coastal inputs. Colony rule and non-unit queue eligibility are not connected.

The native caller supplies a read-only registered presentation lookup. It must
not execute scripts or mutate the world. The actual manufactured-unit factory
checks that presentation against the source design, then prepares home, stack,
sight and manager updates. Base preparation stages Pop assignments, reverse
index, accounting and both update queues. Unit and Base commit without an
intervening callback or allocation; the spawn notification follows both commits.
A failed preparation publishes nothing. This is a port transactional boundary,
not a claim that the original allocator's post-debit refusal refunded minerals.

The method has no GSE posting entry point. The forthcoming turn dispatcher owns
once-per-turn invocation. Population/food collection and the unconditional
second resource pass remain the next composition; this checkpoint alone is not
complete upkeep, energy processing, credits, riots calculation or completion of
facilities/projects/Colony units. Manufacturing currently retains the factory's
separately documented training and presentation restrictions.

The cached native run passes 25 affected tracked allocation, live-knowledge, manual
worker and production groups. Two new actual Base tests complete Scout then
Formers, consume/repeat the queue, observe the third home's support in a fresh
second calculation without posting, preserve valid Doctors, and reject a late
queue candidate without changing Unit IDs, Pops or the saved world. Four changed
production translation units analyze clean. Existing original posting,
queue and ordinary production-loop contracts supply the semantics; these tests
are synthetic live compositions, not new original-executable runs.
