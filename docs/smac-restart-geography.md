# Retained restart geography

The saved territory topology now owns optional regional area history, fertility
totals and coastal flags. The [native producer receipt](behavior/coastal-metadata-and-region-area.md)
and its compiled semantic fixtures distinguish these values from fresh counts
of final region labels. The full raw research remains preserved in the reference
checkout; the fixture contains the literal inputs and complete compared outputs.

Fresh GLSMAC topology starts with an explicit zero area table. Region fill
replaces each discovered ordinary component's count, preserves unused entries,
and adds polar-row counts without subtracting those tiles from ordinary areas.
`Rebuild` retains the previous table and does not refresh postpass data. A
separate `WithTerrainPostpass` replaces fertility and coastal flags using their
recorded predicates and stored areas, including the ordered polar clipping rule.

Generated SMAC maps publish this geography after successful generation. Initial
worker-knowledge and starting-Base admission use the same producer when topology
is absent. DisplayedTerrainV1 converts the port's ARID/FLAT enums to original
ordinal zero, matching the existing resource consumer: arid, rocky and fungal
land do not qualify for fertility. Missing map policy or incomplete land codes
leave the postpass unavailable; they do not manufacture a zero fertility table.
Existing knowledge publication, founding, capture and actual Start preserve the
owned values instead of silently replaying the terrain postpass.

Topology V2 stores the optional data with bounded geometry and exact framing.
V1 restores retain unknown area/postpass history and can roundtrip that absence;
final labels cannot recover earlier polar accumulation. Geometry validation
checks labels without requiring historical counters to equal a fresh rebuild.
The new record does not add Freshwater marking, region-capacity merging, original
world generation or site-rating cache ownership, and does not enable restart
search or last-Base capture yet. Those consumers remain the next integration.

Validation: cached Linux Debug build and 33 affected native integration groups;
the eleven recorded compositions compare 2,816 region labels, 1,408 stored area
words and 2,560 coastal results. Separate tests cover 960/64 fertility totals,
rebuild/postpass separation, V1 migration, malformed metadata, live field
conversion and actual Start retaining a deliberately stale fertility total.
Eleven affected production units (including the ocean-lock review fix) passed
LLVM15 correctness analysis in 18.30s.
