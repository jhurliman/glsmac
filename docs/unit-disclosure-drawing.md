# Ordinary Unit disclosure in live drawing

The ordinary local SMAC frontend now applies the source lookup/head admission
before choosing a stack representative. This connects the [original actor
contract](behavior/live-object-name-stack-admission.md) to actual model, flag,
health-bar and extra stack-badge instances, including direct refresh paths.

An owned snapshot carries retained occupancy, native flags, status, source links,
order/work state and resolved chassis domain. Unknown terrain admits no body.
Own Units normally bypass stored visibility, except the native flags pair0x440;
foreign/exceptional lookup Units require the actual viewer's stored disclosure.
The Base occupancy/tag gate distinguishes a selected active Unit from a held
or inactive garrison. Source stack order is validated before promotion; the
representative uses domain plus own-owner priority and source-order ties. It is
not a per-member visibility filter or stable-ID sort.

The frontend indexes the owned roster by tile and caches presentation plans.
New snapshots, selection changes and active-turn changes invalidate the relevant
plans. Missing ordinary SMAC authority hides Units; the intentionally revealed
inspector and legacy synthetic views remain explicit separate contexts. Model,
primary badge/health bar and extra badge draw calls all enforce admission, and
refresh removes old instances before rebuilding the admitted tile presentation.

Fresh conventional factories now zero DWORD status independently of native
WORD flags and discard derived accounting markers, following the actual
initializer stores in the [factory receipt](behavior/conventional-unit-flags16-authority.md).
Raw imported/restored records preserve their retained fields. Production into
an empty tile extends source links when an existing bound source pool establishes
the namespace; it does not invent ordering for unknown migrated stacks.

  no tracked OpenGL leaks were reported. Heap allocations/audio were not checked.

## Remaining original-game integration

The ordinary static profile does not close editor/special override pointers,
transport/chassis exceptions, display-option/zoom contexts or source blink-phase
selection. The [native stack marker](native-stack-marker.md) now replaces ordinary per-member
flags with one raw representative silhouette and connects actual selection,
startup descriptor and restore-ready callers. Special-view layouts remain open. Tile picking
and lower-console roster disclosure need their separate consumer audit.

An empty native pool and old saves with missing source-pool authority still
need an explicit persistent namespace/migration policy; unknown multi-unit
ordering is not reconstructed from port stable IDs. General terrain cameras,
black/grid unknown rendering, palette/lighting, shoreline masks and full scene
comparison remain open. This change does not turn the revealed inspector into
ordinary exploration rendering.
